# VRM RETRO MAKER

[English](README.md)

ひとつのページに道具が 2 つあります。

1. **VRM → レトロ VRM。** VRM アバター（0.x / 1.0）を開くと、**レトロな VRM** にして返します。色テクスチャを小さくし、全体で 16 / 32 / 64 / 128 / 256 色のひとつのパレットにそろえ、ドットがぼけない設定（nearest）にします。
できあがるのは元と同じバージョンのふつうの VRM なので、ほかの VRM アプリ（VSeeFace、VRoid Hub、three-vrm、Unity など）でも使えます。
保存する前に、231 個の CC0 モーションで動かして、変換前（Before）と変換後（After）を切り替えて確かめられます。

2. **絵 → ボクセル VRM。** キャラクターの絵（PNG / JPG。AI で作った絵など）を開くと、**ボクセルの VRM** にします。
絵をドット絵（高さ 32〜128 px、16〜256 色）にして、1 ドットを 1 本の立方体の柱にします（体の真ん中ほど厚い）。
骨の位置（関節）は自分でドラッグして合わせます。VRM 1.0 と VRM 0.x で保存できます。

[VRM RETRO VIEWER](https://github.com/harukaappscreate/vrm-retro-viewer)、VRM Motion Studio の兄弟ツールです。

ファイルはどこにも送信しません。読み込みも変換も、ブラウザ（または手元のパソコン）の中で行います。

## 変わるもの・変わらないもの

| 変わる | そのまま |
|---|---|
| 色テクスチャ（ベースカラー、MToon の影色。0.x は `_MainTex` / `_ShadeTexture`）。選んだ大きさ（最大 64 / 128 / 256 px、拡大はしない）に縮め、共通パレットに減色し、PNG で保存 | ボーン、ウェイト、メッシュ、表情（ブレンドシェイプ）、揺れもの（スプリングボーン）、コライダー、視線、一人称設定 |
| それらのテクスチャに nearest のサンプラー | マテリアルとその設定、ノーマルマップなど色以外のテクスチャ、サムネイル |
| | ライセンス情報（meta）と VRM のバージョン |

ライセンスで改変が禁止されているアバターは変換しません（VRM 1.0 の `modification: prohibited`、VRM 0.x の `Redistribution_Prohibited` と `*_ND` 系）。
それ以外も、できたファイルを使ったり配ったりするときは元のライセンスに従ってください。

## 絵 → ボクセル VRM のしくみ

1. **切り抜き。** 透明部分のある PNG はそのまま。ほかは、縁につながっていて縁の色に近いところを背景とします（「Background cut」で近さを変えられます）。
2. **ドット絵。** 選んだ高さに縮め、ひとつのパレットに減色します。
3. **関節。** 輪郭から首・股・肩・肘・手首・脚の付け根・膝・足首を推測します。画面で確かめて、ずれていたらドラッグで直します（Mirror をオンにすると左右がいっしょに動きます）。「Arm thickness」は腕として切り出す太さです（青い円）。
4. **T ポーズ。** VRM は腕を横にまっすぐ伸ばした姿勢が基本です。元の大きな絵から腕を切り出して肩を中心に回し、腕が隠していた体の部分は横の体の色で埋めます。そのあとでドット絵を作り直します。
5. **ボクセル。** 各ドットを、その部位の縁からの距離に応じた厚さの柱にします（「Body depth」）。背中側も正面と同じ色です。柱ごとに 1 本の骨で動きます（ブロック人形のように、なめらかには曲がりません）。
6. **VRM。** メッシュ 1 つ、16 × 16 のパレット画像 1 枚（くっきりしたドット、ライティングなし）、人型の骨 17 本、サムネイルはドット絵。表情と揺れものはありません。

**複数の向き（3 面図・4 面図）。** 同じ人物が 2〜4 体並んだ絵（正面・横・背面・反対の横、すべて T ポーズ）は、自動で向きごとに分けて役割（正面 / 背面 / 右向きの横 / 左向きの横。横の向きは足先で判断）を付けます。役割はページで変えられます。そのうえで:
- **横の絵で奥行き**を決めます。正面と横の両方で体がある所にだけ立方体を残します（腕は横から見ると体に隠れるので、腕だけは膨らませる方式のまま）。
- **背面の絵で背中の色**、横の絵で側面の色を付けます。

- **色のまとまり**（髪・肌・服など）ごとに形を作ります。横の絵の各段で、体の前後にある同じ色の部分は、背面（または正面）の絵の同じ色の幅を使います。ポニーテールが体の幅の板にならず、房になります。
- 骨の境目では立方体の内側の面も作るので、関節を曲げても穴が見えません。

**緑の背景**（#00FF00）は、ポニーテールと頭の間も含めて全部抜けます。白い背景では、囲まれた背景色のすき間も抜きます（「Cut out closed-in background」。白い服のときはオフ）。シートの上で隣と触れている人物（指先が隣の髪に触れるなど）も分けます。

向きごとに同じ高さにそろえ、体の真ん中で位置を合わせるので、AI の 3 面図によくある少しのずれはならされます。AI の 4 面図 1 枚（2576 × 1438）で試し、分け方と役割は正しく、長い髪とマントが横と後ろから見えることを確かめました。

**新しいアバターのライセンス。** 最初はいちばん厳しい選択（作者だけが使える、個人の非営利、再配布不可、改変不可、クレジット必須）が入っています。ダウンロードの前に必要なら変えてください。VRM 0.x は項目が少ないので、商用は許可 / 不許可だけ、「再配布不可」は `Redistribution_Prohibited` になります。

**絵について。** 自分で作った絵か、使ってよい絵だけを使ってください。AI の絵は、使ったサービスの規約を確かめてください。実在の人を本人の同意なく使わないこと、他人のキャラクターを使わないこと。そのことを確かめるチェックを入れるまで、ダウンロードはできません。

向いている絵: キャラクター 1 人、正面向き、立ち姿、腕が体から少し離れている、背景が無地。腰に手・腕組み・横向き・ごちゃごちゃした背景は、直す手間が増えるか、うまくいきません。

## 手元で動かす

Python 3 と Pyxel 3 が必要です（`pip install pyxel numpy pillow`）。

```bash
python main.py                 # ウィンドウに .vrm をドロップ
python main.py avatar.vrm      # ファイルを直接開く
```

キー: **R** レトロにする（64 色、128 px）、**TAB** 変換前 / 変換後、**S** レトロ VRM を main.py の隣に保存、SPACE 次のモーション、T T ポーズ、P スクリーンショット、G GIF、L ライセンス。
絵のとき: 関節をドラッグ、**M** VRM を作る、**J** 関節を推測し直す、**X** ミラーのオン / オフ。できたら **S** VRM 1.0 を保存、**SHIFT+S** VRM 0.x を保存、**E** 関節の編集に戻る。（デスクトップ版ではライセンスは厳しい初期値のままです。変えるときはブラウザ版を使ってください。）

コマンドラインだけで変換する場合（ウィンドウなし）:

```bash
python vrm_retro.py avatar.vrm avatar_retro.vrm 64 128     # 色数、テクスチャの最大サイズ
python img2vrm.py picture.png avatar.vrm 64 32              # ドット絵の高さ、色数（--0x で VRM 0.x）
```

**ブラウザ版:** `web/index.html` と `web/vrm_retro_maker.pyxapp`。`web` フォルダをサーバーで配信して（例: その中で `python -m http.server`）開きます。
`.pyxapp` と itch.io 用 zip の作り直し: `python tools/build_web.py`

## 確認したこと

- 千駄ヶ谷 渋（VRM 1.0、CC0）と three-vrm-girl（VRM 0.x、pixiv）を 16 / 64 / 256 色で変換。glTF Validator の結果は元ファイルと同じ（エラー 0）
- どちらも VRM RETRO VIEWER で読み込めて、モーションで動く
- 絵 → VRM：スクリプトで描いた試験用の人物（ズボン、スカートと長い髪、腕を広げた姿）で、VRM 1.0 / 0.x とも glTF Validator でエラー 0、three-vrm 3.5.5 で読み込める（必須の骨 15 本そろう、meta も正しく読める）、VRM RETRO VIEWER で歩く・パンチする。本物の AI の絵ではまだ試していない
